# CSS Learning Documentation

This document summarizes the CSS concepts and challenges completed as part of the Codedex curriculum.

## Overview
CSS (Cascading Style Sheets) describes how HTML elements are to be displayed on screen, paper, or in other media.

## Key Concepts Covered

### 1. Selectors and Specificity
- **Element Selectors**: Styling tags directly (e.g., `body`, `h1`).
- **ID Selectors**: Using `#id` for unique elements.
- **Class Selectors**: Using `.class` for reusable styles (if applicable).
- **Universal Selector**: `*` for styling all elements.

### 2. Colors and Typography
- `color`: Changing text color.
- `background-color`: Setting background colors.
- `font-family`: Setting typefaces.
- `text-align`: Aligning text (center, left, right).

### 3. Box Model
- **Margin**: Space outside the border.
- **Border**: A line around the element.
- **Padding**: Space inside the border, around the content.
- **Content**: The actual content of the box.
- `box-sizing: border-box`: Ensuring padding/border doesn't increase element width.

### 4. Layout and Positioning
- `width` and `height`: Controlling size.
- `display`: Controlling element behavior (block, inline-block, none).
- `position`: Static, relative, absolute, fixed.
- `float`: (Traditional method) Pushing elements to left/right.

### 5. Advanced Styling
- `background-image`: Using images for backgrounds.
- `border-radius`: Rounded corners.
- `list-style`: Customizing list bullets/numbers.
