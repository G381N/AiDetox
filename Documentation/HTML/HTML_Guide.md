# HTML Learning Documentation

This document summarizes the HTML concepts and challenges completed as part of the Codedex curriculum.

## Overview
HTML (HyperText Markup Language) is the standard markup language for documents designed to be displayed in a web browser.

## key Concepts Covered

### 1. Basic Structure
- `<!DOCTYPE html>`: Defines the document type.
- `<html>`: The root element.
- `<head>`: Contains meta-information about the document (title, styles, etc.).
- `<body>`: Contains the visible page content.

### 2. Text Elements
- Headings (`<h1>` to `<h6>`)
- Paragraphs (`<p>`)
- Formatting (`<b>`, `<i>`, `<strong>`, `<em>`)

### 3. Lists and Images
- Unordered Lists (`<ul>`) and Ordered Lists (`<ol>`)
- List Items (`<li>`)
- Images (`<img src="..." alt="...">`)

### 4. Links and Navigation
- Anchor tags (`<a href="...">`) for linking to other pages or sections (using IDs).

### 5. Forms
- `<form>` element to wrap input controls.
- Input types: `text`, `radio`, `checkbox`, `number`, `submit`.
- `<label>` for accessibility.
- `<textarea>` for multi-line text.
- Attributes like `required`, `placeholder`, `rows`, `cols`.
