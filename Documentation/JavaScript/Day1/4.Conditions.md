# Day 3 – Conditions in JavaScript

---

## 1. What Are Conditions?

Conditions are used to **make decisions in code**.

They allow JavaScript to:

* Execute certain code **only if a condition is true**
* Choose between multiple paths based on logic

---

## 2. `if` / `else`

The `if` statement runs code **when a condition is true**.

```js
let age = 18;

if (age >= 18) {
  console.log("Eligible to vote");
} else {
  console.log("Not eligible to vote");
}
```

* If condition is `true` → `if` block runs
* If condition is `false` → `else` block runs

---

## 3. `else if` (Multiple Conditions)

Used when you need to check **more than one condition**.

```js
let marks = 75;

if (marks >= 90) {
  console.log("Grade A");
} else if (marks >= 60) {
  console.log("Grade B");
} else {
  console.log("Fail");
}
```

JavaScript checks conditions **top to bottom** and stops when one is true.

---

## 4. Nested Conditions

An `if` statement inside another `if` is called **nested if**.

```js
let age = 20;
let hasID = true;

if (age >= 18) {
  if (hasID) {
    console.log("Entry allowed");
  } else {
    console.log("ID required");
  }
} else {
  console.log("Underage");
}
```

Used when decisions depend on **multiple levels of conditions**.

---

## 5. `switch` Case

The `switch` statement is used when comparing **one value against many options**.

```js
let day = 3;

switch (day) {
  case 1:
    console.log("Monday");
    break;
  case 2:
    console.log("Tuesday");
    break;
  case 3:
    console.log("Wednesday");
    break;
  default:
    console.log("Invalid day");
}
```

### Important Points:

* `case` checks for a match
* `break` stops execution
* `default` runs if no case matches

---

## When to Use What?

* Use `if / else` for **range-based conditions**
* Use `switch` for **fixed values**
