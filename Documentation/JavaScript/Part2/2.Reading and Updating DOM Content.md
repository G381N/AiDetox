# Day 4 – Reading & Updating DOM Content

---

## 1. Reading & Updating Text Content

JavaScript provides different properties to **read or change content** inside HTML elements.
They look similar but behave differently — this is important.

---

## 2. `.innerText`

* Returns **only visible text**
* Respects CSS (hidden text is ignored)
* Slower because it checks styling

```html
<p id="para">Hello <span style="display:none">World</span></p>
```

```js
let p = document.getElementById("para");
console.log(p.innerText);
```

Output:

```
Hello
```

Use when:

* You care about what the user **actually sees**

---

## 3. `.textContent`

* Returns **all text**, even hidden
* Ignores CSS
* Faster and more predictable

```js
console.log(p.textContent);
```

Output:

```
Hello World
```

Use when:

* You want raw text
* Performance matters

---

## 4. `.innerHTML`

* Returns or sets **HTML + text**
* Can insert HTML elements
* Powerful but dangerous if misused

```html
<div id="box"></div>
```

```js
box.innerHTML = "<h2>Hello</h2>";
```

⚠️ Warning:

* Can cause **XSS attacks** if user input is inserted directly

Use when:

* You intentionally want to insert HTML

---

## 5. `.value` (For Inputs)

Used to **get or set value** of form inputs.

```html
<input type="text" id="name">
```

```js
let input = document.getElementById("name");

console.log(input.value);   // get value
input.value = "Gebin";      // set value
```

Used for:

* Forms
* Search boxes
* User input handling

---

## 6. Setting Attributes

### `setAttribute()`

Used to set or update an HTML attribute.

```html
<img id="img">
```

```js
let img = document.getElementById("img");
img.setAttribute("src", "image.png");
img.setAttribute("alt", "Profile Image");
```

---

## 7. Working with Classes (`classList`)

### `.classList.add()`

Adds a class.

```js
box.classList.add("active");
```

---

### `.classList.remove()`

Removes a class.

```js
box.classList.remove("active");
```

---

### `.classList.toggle()`

Adds class if missing, removes if present.

```js
box.classList.toggle("active");
```

Common use case:

* Dark mode
* Show / hide elements
* Active states

---

## Quick Comparison

| Property      | What it Handles   | Use Case         |
| ------------- | ----------------- | ---------------- |
| `innerText`   | Visible text only | UI text          |
| `textContent` | All text          | Raw content      |
| `innerHTML`   | HTML + text       | Dynamic HTML     |
| `value`       | Input values      | Forms            |
| `classList`   | CSS classes       | Styling & states |

---

## Summary

* `innerText` → visible text
* `textContent` → all text
* `innerHTML` → HTML content
* `value` → input fields
* `setAttribute()` → modify attributes
* `classList` → manage CSS classes
