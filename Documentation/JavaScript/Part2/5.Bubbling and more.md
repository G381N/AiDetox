## 1. Event Bubbling (IMPORTANT)

### What is Event Bubbling?

**Event bubbling** means:

> An event starts from the **target element** and moves **upward to its parent elements**.

### Example Structure

```html
<ul id="list">
  <li>
    <button>Delete</button>
  </li>
</ul>
```

### Example Code

```js
document.getElementById("list").addEventListener("click", () => {
  console.log("UL clicked");
});

document.querySelector("button").addEventListener("click", () => {
  console.log("Button clicked");
});
```

### Output when button is clicked:

```
Button clicked
UL clicked
```

👉 Event flows **button → li → ul → body → document**

## 2. Why Event Delegation is Needed

### Problem (Without Delegation)

* Every new task needs its own delete/edit event
* Too many event listeners
* Poor performance

❌ Bad approach:

```js
deleteBtn.addEventListener("click", () => {
  task.remove();
});
```

---

### Solution: Event Delegation

Attach **one event listener to the parent** and detect the target.

✔ Better approach:

```js
list.addEventListener("click", (event) => {
  if (event.target.classList.contains("delete")) {
    event.target.parentElement.remove();
  }
});
```

Benefits:

* Works for dynamically added elements
* Cleaner code
* Better performance

## 3. Event Delegation – To-Do Example

### HTML

```html
<ul id="todoList">
  <li>
    Task 1
    <button class="delete">Delete</button>
    <button class="edit">Edit</button>
  </li>
</ul>
```

---

### JavaScript

```js
const todoList = document.getElementById("todoList");

todoList.addEventListener("click", (event) => {
  if (event.target.classList.contains("delete")) {
    event.target.parentElement.remove();
  }

  if (event.target.classList.contains("edit")) {
    alert("Edit clicked");
  }
});
```

## 4. ES6 Basics (Required Parts)

---

### 4.1 `let` and `const` (Recap)

```js
let count = 0;
count = 1;

const appName = "Todo App";
// appName = "New" ❌
```

* Use `const` by default
* Use `let` if value changes

---

### 4.2 Arrow Functions in DOM Handlers

Old way:

```js
button.addEventListener("click", function () {
  console.log("Clicked");
});
```

Modern ES6 way:

```js
button.addEventListener("click", () => {
  console.log("Clicked");
});
```

Cleaner and shorter.

---

### 4.3 Template Literals (VERY IMPORTANT)

Used to build HTML dynamically.

```js
const task = "Learn JS";

const html = `
  <li>
    ${task}
    <button class="delete">Delete</button>
  </li>
`;

todoList.insertAdjacentHTML("beforeend", html);
```

* Uses backticks (`` ` ``)
* `${}` for variables

---

### 4.4 Destructuring (Basic)

Extract values easily.

```js
const user = { name: "Jebin", age: 20 };

const { name, age } = user;
```

Array example:

```js
const nums = [1, 2, 3];
const [a, b] = nums;
```

---

### 4.5 Spread Operator (Quick Intro)

Used to copy or merge arrays/objects.

```js
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4];
```

Object example:

```js
const user = { name: "Jebin" };
const newUser = { ...user, age: 20 };
```

## 5. JavaScript Modules (Intro Level)

---

### 5.1 Why Modules?

Modules help:

* Organize code
* Avoid global variables
* Improve maintainability

---

### 5.2 `export` and `import`

#### Export (todo.js)

```js
export function addTask(task) {
  console.log(task);
}
```

#### Import (main.js)

```js
import { addTask } from "./todo.js";

addTask("Learn JS");
```

## 6. Splitting Files (To-Do App Structure)

### `todo.js` (Logic)

```js
export let tasks = [];

export function addTask(task) {
  tasks.push(task);
}
```

---

### `ui.js` (DOM Updates)

```js
export function renderTasks(tasks) {
  console.log(tasks);
}
```

---

### `main.js` (Entry Point)

```js
import { addTask, tasks } from "./todo.js";
import { renderTasks } from "./ui.js";
```
