# Day 4 – DOM Basics (JavaScript)

---

## 1. What is the DOM?

**DOM** stands for **Document Object Model**.

When a browser loads an HTML page:

* It converts HTML into a **tree-like structure**
* This structure is called the **DOM Tree**
* JavaScript interacts with this tree, **not raw HTML**

### HTML → DOM Tree (Concept)

```html
<body>
  <h1>Hello</h1>
  <p>Welcome</p>
</body>
```

DOM Tree (simplified):

```
document
 └── body
     ├── h1
     └── p
```

JavaScript can **read, change, add, or delete** elements using the DOM.

---

## 2. The `document` Object

The `document` object represents the **entire web page**.

* It is the **entry point** to the DOM
* All DOM operations start from `document`

Example:

```js
console.log(document);
```

Common uses:

* Selecting elements
* Creating elements
* Listening to events

---

## 3. Selecting Elements from the DOM

To manipulate HTML elements, JavaScript must **select them first**.

---

### 3.1 `getElementById()`

Selects **one element** by its `id`.

```html
<h1 id="title">Hello</h1>
```

```js
let title = document.getElementById("title");
console.log(title);
```

* Returns **a single element**
* Most commonly used
* `id` must be unique

---

### 3.2 `getElementsByClassName()`

Selects elements by class name.

```html
<p class="text">One</p>
<p class="text">Two</p>
```

```js
let texts = document.getElementsByClassName("text");
console.log(texts);
```

* Returns **HTMLCollection**
* Multiple elements
* Access using index

```js
console.log(texts[0]);
```

---

### 3.3 `getElementsByTagName()`

Selects elements by HTML tag name.

```html
<li>Item 1</li>
<li>Item 2</li>
```

```js
let items = document.getElementsByTagName("li");
console.log(items);
```

* Returns **HTMLCollection**
* Used when selecting by tag

---

### 3.4 `querySelector()`

Selects the **first matching element** using CSS selector.

```html
<div class="box"></div>
```

```js
let box = document.querySelector(".box");
```

Examples:

```js
document.querySelector("#title");   // by id
document.querySelector(".text");    // by class
document.querySelector("p");        // by tag
```

---

### 3.5 `querySelectorAll()`

Selects **all matching elements** using CSS selector.

```html
<p class="item">A</p>
<p class="item">B</p>
```

```js
let items = document.querySelectorAll(".item");
```

* Returns **NodeList**
* Can use `forEach`

```js
items.forEach(item => {
  console.log(item);
});
```

---

## 4. Quick Comparison

| Method                   | Returns        | Notes                  |
| ------------------------ | -------------- | ---------------------- |
| `getElementById`         | Single Element | Fast, most common      |
| `getElementsByClassName` | HTMLCollection | Multiple elements      |
| `getElementsByTagName`   | HTMLCollection | By tag                 |
| `querySelector`          | Single Element | CSS selector           |
| `querySelectorAll`       | NodeList       | CSS selector, iterable |
