# Day 4 – Events in JavaScript (Main Focus)

> **Events are the heart of interactivity.**
> If you don’t understand events, DOM is useless. Read this carefully.

---

## 1. What is an Event?

An **event** is **something that happens in the browser** that JavaScript can react to.

Examples:

* User clicks a button
* User types in an input
* User submits a form
* User presses a key

👉 JavaScript **listens** for events and **responds** with code.

---

## 2. `addEventListener()`

Used to **attach an event to an element**.

### Syntax

```js
element.addEventListener("eventType", function);
```

### Example (Click Event)

```html
<button id="btn">Click Me</button>
```

```js
const btn = document.getElementById("btn");

btn.addEventListener("click", () => {
  console.log("Button clicked");
});
```

What happens:

* User clicks the button
* Function runs

---

## 3. Event Types (With Examples)

---

### 3.1 `click`

Triggered when the user clicks an element.

```js
btn.addEventListener("click", () => {
  alert("Clicked!");
});
```

Used for:

* Buttons
* Icons
* Delete/Edit actions

---

### 3.2 `submit`

Triggered when a form is submitted.

```html
<form id="myForm">
  <input type="text">
  <button type="submit">Submit</button>
</form>
```

```js
const form = document.getElementById("myForm");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  console.log("Form submitted");
});
```

Used for:

* Login
* Signup
* Forms

---

### 3.3 `keydown`

Triggered when a key is **pressed down**.

```js
document.addEventListener("keydown", (event) => {
  console.log(event.key);
});
```

Example use:

* Detect Enter key
* Keyboard shortcuts

---

### 3.4 `keyup`

Triggered when a key is **released**.

```js
document.addEventListener("keyup", (event) => {
  console.log("Key released:", event.key);
});
```

Used when:

* You need final input value after typing

---

### 3.5 `change`

Triggered when input **loses focus and value changes**.

```html
<select id="country">
  <option>India</option>
  <option>USA</option>
</select>
```

```js
const select = document.getElementById("country");

select.addEventListener("change", () => {
  console.log(select.value);
});
```

Used for:

* Dropdowns
* Checkboxes
* Radio buttons

---

### 3.6 `input`

Triggered **every time value changes**.

```html
<input type="text" id="name">
```

```js
const input = document.getElementById("name");

input.addEventListener("input", () => {
  console.log(input.value);
});
```

Used for:

* Live validation
* Search suggestions
* Character counters

---

## 4. Event Object (`event`)

When an event occurs, JavaScript automatically provides an **event object**.

```js
btn.addEventListener("click", (event) => {
  console.log(event);
});
```

---

### 4.1 `event.target`

Refers to the **exact element that triggered the event**.

```html
<button class="delete">Delete</button>
```

```js
document.addEventListener("click", (event) => {
  console.log(event.target);
});
```

Used heavily in:

* Event delegation
* To-do apps

---

## 5. Prevent Default Form Reload

### Problem

By default, form submission:

* Reloads the page
* Clears JavaScript state

---

### Solution: `event.preventDefault()`

```js
form.addEventListener("submit", (event) => {
  event.preventDefault();
  console.log("Form handled by JS");
});
```

Now:

* Page does NOT reload
* JavaScript controls form logic

---

## 6. Full Practical Example – Form Submit

```html
<form id="loginForm">
  <input type="text" id="username">
  <button type="submit">Login</button>
</form>
```

```js
const form = document.getElementById("loginForm");

form.addEventListener("submit", (event) => {
  event.preventDefault();

  const username = document.getElementById("username").value;

  if (username === "") {
    alert("Username required");
  } else {
    alert("Welcome " + username);
  }
});
```

---

## Summary

* Events are actions performed by the user
* `addEventListener()` attaches event handlers
* Common events: `click`, `submit`, `keydown`, `keyup`, `change`, `input`
* `event` object gives details about the event
* `event.target` tells which element triggered the event
* `event.preventDefault()` stops default browser behavior
