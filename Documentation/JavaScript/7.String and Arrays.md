# Day 3 – Array Operations & String Operators (JavaScript)

---

## 1. Arrays in JavaScript

An **array** is used to store multiple values in a single variable.

```js
let numbers = [10, 20, 30, 40];
let names = ["Alice", "Bob", "Charlie"];
```

Array indexing starts from **0**.

```js
console.log(numbers[0]); // 10
```

---

## 2. Common Array Operations

### 2.1 Accessing Elements

```js
let fruits = ["Apple", "Banana", "Mango"];
console.log(fruits[1]); // Banana
```

---

### 2.2 Adding Elements

**Add to the end – `push()`**

```js
fruits.push("Orange");
```

**Add to the beginning – `unshift()`**

```js
fruits.unshift("Grapes");
```

---

### 2.3 Removing Elements

**Remove from the end – `pop()`**

```js
fruits.pop();
```

**Remove from the beginning – `shift()`**

```js
fruits.shift();
```

---

### 2.4 Array Length

```js
console.log(fruits.length);
```

---

### 2.5 Looping Through an Array

```js
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
```

---

### 2.6 Finding Elements

**`indexOf()`**

```js
fruits.indexOf("Banana"); // returns index or -1
```

**`includes()`**

```js
fruits.includes("Apple"); // true
```

---

### 2.7 Extracting & Modifying Arrays

**`slice()` – extract a portion**

```js
let newFruits = fruits.slice(1, 3);
```

**`splice()` – add/remove elements**

```js
fruits.splice(1, 1); // removes 1 element at index 1
```

---

## 3. Strings in JavaScript

Strings represent **text data** and are written inside quotes.

```js
let language = "JavaScript";
```

---

## 4. String Operators

### 4.1 String Concatenation (`+`)

```js
let first = "Hello";
let second = "World";

let message = first + " " + second;
```

---

### 4.2 Concatenation Using `+=`

```js
let text = "Hello";
text += " User";
```

---

## 5. Common String Operations

### 5.1 String Length

```js
let word = "Hello";
console.log(word.length); // 5
```

---

### 5.2 Accessing Characters

```js
console.log(word[0]); // H
```

---

### 5.3 Case Conversion

```js
word.toUpperCase(); // "HELLO"
word.toLowerCase(); // "hello"
```

---

### 5.4 Searching in Strings

**`includes()`**

```js
word.includes("He"); // true
```

**`indexOf()`**

```js
word.indexOf("e"); // 1
```

---

### 5.5 Extracting Text

**`slice()`**

```js
word.slice(1, 4); // "ell"
```

---

### 5.6 Replacing Text

```js
word.replace("Hello", "Hi");
```

---

### 5.7 Converting String to Array

**`split()`**

```js
let data = "a,b,c";
let arr = data.split(",");
```

---

### 5.8 Removing Extra Spaces

**`trim()`**

```js
let input = "  hello  ";
input.trim(); // "hello"
```

---

## Summary

### Arrays

* Store multiple values in one variable
* Index starts at 0
* Common methods:

  * `push`, `pop`
  * `shift`, `unshift`
  * `length`
  * `indexOf`, `includes`
  * `slice`, `splice`

### Strings

* Used for text data
* `+` and `+=` for concatenation
* Common methods:

  * `length`
  * `toUpperCase`, `toLowerCase`
  * `includes`, `indexOf`
  * `slice`, `replace`
  * `split`, `trim`
