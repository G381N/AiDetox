# Day 3 – Functions in JavaScript

---

## 1. What Are Functions?

Functions are **blocks of code designed to perform a specific task**.

They help to:

* Reuse code
* Organize logic
* Avoid repetition

---

## 2. Function Declaration vs Function Expression

### Function Declaration

A function declared using the `function` keyword.

```js
function add(a, b) {
  return a + b;
}
```

* Can be called **before it is defined**
* Fully hoisted by JavaScript

```js
add(2, 3); // works
```

---

### Function Expression

A function stored inside a variable.

```js
const add = function(a, b) {
  return a + b;
};
```

* Cannot be called before definition
* Treated as a value
* More predictable execution

```js
add(2, 3); // works (only after definition)
```

---

## 3. Parameters and Return Values

### Parameters

Parameters are **inputs** given to a function.

```js
function greet(name) {
  console.log("Hello " + name);
}
```

### Return Values

The `return` statement sends a value back from the function.

```js
function sum(a, b) {
  return a + b;
}

let result = sum(5, 3); // result = 8
```

Without `return`, a function returns `undefined`.

---

## 4. Default Parameters

Default parameters are used when **no argument is passed**.

```js
function greet(name = "Guest") {
  console.log("Hello " + name);
}

greet();        // Hello Guest
greet("Jebin"); // Hello Jebin
```

This prevents errors from missing values.

---

## 5. Arrow Functions

Arrow functions are a **shorter syntax** for function expressions.

### Syntax

```js
const add = (a, b) => {
  return a + b;
};
```

### Shorter Version

```js
const add = (a, b) => a + b;
```

* Cleaner and modern syntax
* Commonly used in modern JavaScript frameworks

---

## 6. Scope Basics (Global vs Local)

### Global Scope

Variables declared **outside functions**.

```js
let x = 10;

function show() {
  console.log(x);
}
```

Accessible everywhere.

---

### Local Scope

Variables declared **inside functions**.

```js
function test() {
  let y = 5;
  console.log(y);
}

test();
// console.log(y); ❌ error
```

Accessible only inside the function.
