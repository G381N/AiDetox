# Day 3 – Loops in JavaScript

---

## 1. What Are Loops?

Loops are used to **repeat a block of code multiple times**.

Instead of writing the same code again and again, loops help:

* Reduce repetition
* Handle repetitive tasks
* Work with sequences of numbers or data

---

## 2. `for` Loop

The `for` loop is used when you **know how many times** the loop should run.

### Syntax

```js
for (initialization; condition; increment/decrement) {
  // code to repeat
}
```

### Example

```js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

Explanation:

* Initialization → `let i = 1`
* Condition → `i <= 5`
* Increment → `i++`

---

## 3. `while` Loop

The `while` loop runs **as long as the condition is true**.

### Syntax

```js
while (condition) {
  // code to repeat
}
```

### Example

```js
let i = 1;

while (i <= 5) {
  console.log(i);
  i++;
}
```

⚠️ Always update the condition, or the loop will run forever.

---

## 4. `do...while` Loop

The `do...while` loop runs **at least once**, even if the condition is false.

### Syntax

```js
do {
  // code to repeat
} while (condition);
```

### Example

```js
let i = 6;

do {
  console.log(i);
  i++;
} while (i <= 5);
```

Output:

```
6
```

The code runs once before checking the condition.

---

## 5. `break` and `continue`

### `break`

Used to **stop the loop completely**.

```js
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    break;
  }
  console.log(i);
}
```

Output:

```
1
2
```

---

### `continue`

Used to **skip the current iteration** and continue with the next one.

```js
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue;
  }
  console.log(i);
}
```

Output:

```
1
2
4
5
```

---

## When to Use Which Loop?

* Use `for` when the number of iterations is known
* Use `while` when the condition controls repetition
* Use `do...while` when the code must run at least once
