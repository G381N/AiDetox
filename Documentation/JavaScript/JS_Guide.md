# JavaScript Learning Documentation

This document summarizes the JavaScript concepts and challenges completed as part of the Codedex curriculum.

## Overview
JavaScript is a programming language that adds interactivity to your website.

## Key Concepts Covered

### 1. Basics
- **Console**: Printing output with `console.log()`.
- **Variables**: Storing data using `let`, `const`, and `var`.
- **Data Types**: Strings, Numbers, Booleans.

### 2. Control Flow
- **Conditionals**: `if`, `else if`, `else` statements to make decisions.
- **Loops**: `for` loops to repeat actions (e.g., "I Must Not Tell Lies").

### 3. Functions and Methods
- Defining sets of instructions to perform specific tasks.
- Using built-in methods.

### 4. Objects and Arrays
- **Objects**: Storing collections of data (properties) and functionality (methods).
  - Example: `departTripTicket` object (Code pg38).
- **Arrays**: Ordered lists of values.

### 5. DOM Manipulation
- Interacting with HTML elements via JavaScript.
- Handling events (clicks, input).
